# 📦 Инструкция по сборке кроссплатформенных версий

Проект «Интерактивная красная книга Республики Беларусь» построен на **единой кодовой базе на языке Python (фреймворк Flet на графическом движке Flutter)**.

---

## 1. 🖥️ Сборка для ПК (Windows Desktop `.exe`)
Для создания автономного исполняемого файла Windows без необходимости установки Python на целевом компьютере:
```bash
# Установка сборщика Flet
flet build windows
```
Результат сборки находится в папке `build/windows/` — автономный `.exe` файл, готовый к запуску на школьных компьютерах, интерактивных досках и персональных ПК.

---

## 2. 📱 Сборка для Android (`.apk`)
Сборка установочного файла для мобильных телефонов и планшетов под управлением Android:
```bash
flet build apk
```
Сгенерированный файл `.apk` можно передавать учащимся напрямую через мессенджер, выкладывать на сайт школы/ВУЗа или в RuStore без привязки к Google Play.

---

## 3. 🍏 Работа на iPhone (iOS) без App Store
Поскольку публикация в Apple App Store сопряжена со сложностями и платными аккаунтами разработчика Apple Developer Program ($99/год), используется стандартизированная мировая технология **Progressive Web App (PWA)**:

1. Приложение запускается на локальном или школьном сервере в веб-режиме:
   ```bash
   python run.py --web
   ```
2. Пользователь на iPhone открывает Safari, переходит по адресу/QR-коду приложения.
3. Нажимает кнопку **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой“»** (Add to Home Screen).
4. На экране iPhone появляется полноценная иконка «Красная книга РБ». При запуске приложение раскрывается **на весь экран без адресной строки браузера**, с плавными анимациями 120 FPS и поддержкой локального офлайн-кэша.
