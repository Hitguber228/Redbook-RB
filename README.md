## 📖 Об описании и актуальности проекта

В современных условиях цифровизации образования интерактивные электронные ресурсы становятся неотъемлемым элементом образовательного процесса. Существующая цифровая версия Красной книги Республики Беларусь, созданная в 2006 году, носит преимущественно статичный справочный характер, не содержит интерактивных карт, викторин и не адаптирована под мобильные устройства.

Данный проект решает эту проблему, объединяя в **единой кодовой базе на языке Python**:
1. **Научный биологический паспорт видов** по 4 официальным категориям охраны Республики Беларусь (I, II, III, IV).
2. **Тройную номенклатуру**: Русский язык, Беларуская мова, Международная латынь.
3. **Аутентичную биоакустику**: записи голосов редких птиц и звуков природы.
4. **Интерактивные карты биотопов и ООПТ Беларуси**: Беловежская пуща, Березинский заповедник, Припятский, Нарочанский, Браславские озера, Споровский заказник и др.
5. **Образовательный блок**: интерактивные викторины («Угадай по голосу», «Следопыт», «Красная книга или нет?») с подсчетом баллов и ранговой системой.
6. **Искусственный Интеллект (Computer Vision & RAG)**: определение редких видов и отпечатков следов, диалоговый ассистент-натуралист с базой знаний законов РБ (ст. 16.8 КоАП РБ).
7. **100% Офлайн-режим (Offline-First)**: надежное локальное хранение данных в реляционной базе **SQLite**.

## 🚀 Установка и запуск

### 1. Установка зависимостей
Убедитесь, что у вас установлен Python версии 3.10 или выше:
```bash
pip install -r requirements.txt
```

### 2. Запуск в десктопном режиме (Windows):
```bash
python run.py
```
*Откроется плавное нативное приложение для ПК с широкой версткой.*

### 3. Запуск в веб-режиме (для тестирования на iPhone и Android):
```bash
python run.py --web
```
*Приложение запустится в браузере по адресу `http://localhost:8550`, готовое для добавления на домашний экран смартфона.*

## 🌿 Категории природоохранной значимости (Красная книга РБ)

В приложении строго реализована государственная шкала редкости:
* 🔴 **I Категория (CR)** — На грани исчезновения (*Вертлявая камышевка*);
* 🟠 **II Категория (EN)** — Исчезающие (*Европейский зубр*, *Европейская рысь*, *Жук-олень*);
* 🟡 **III Категория (VU)** — Уязвимые (*Черный аист*, *Болотная черепаха*, *Обыкновенная медянка*, *Венерин башмачок*, *Спарассис курчавый*);
* 🟢 **IV Категория (NT)** — Требующие контроля (*Сон-трава / Прострел раскрытый*).
